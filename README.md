# Universal Music

Music streaming client that plays YouTube tracks without ads and with privacy: search, playlists, queue, and sync across desktop and mobile.

## Features

- Plays tracks and playlists from YouTube without ads
- Spotify playlist import, artist browsing, and lyrics display
- Cross-platform: Android, Windows, macOS, Linux, iOS
- Skip-silence, normalized volume, and sleep timer
- Plugin system for custom playback providers

## Install

- Download a prebuilt binary from the releases page (Android APK, desktop installers)
- Build from source: `gradlew assembleDebug` (Kotlin Multiplatform, JDK 17)
